# DrawioDiagrams

Creates, edits, validates, and exports draw.io diagrams using native .drawio XML, consistent layouts, clear visual hierarchy, and reviewable architecture conventions.

## What this skill covers

- Practical guidance for drawio diagrams workflows.
- A consistent process for reviewing requirements, making decisions, and validating results.
- Use `SKILL.md` as the primary reference.
